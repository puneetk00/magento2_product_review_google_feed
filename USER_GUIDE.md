# Productfeed User Guide

## What this module does

`Pkgroup_Productfeed` exports existing Magento product reviews as
Google Merchant Center Product Reviews XML 2.4. It creates one feed per store
view. It does not collect reviews, send invitations, moderate reviews, or
submit feeds to Google.

## Generate a feed now

From the Magento project root, generate feeds for all store views:

```bash
php bin/magento productreview:feed
```

Generate a feed for one store view using its store code:

```bash
php bin/magento productreview:feed --store=default
```

The command prints the generated file path and public URL. For store ID `1`,
the static feed is:

```text
File: pub/productreview/feed/store-1.xml
URL:  https://<store-domain>/productreview/feed/store-1.xml
```

The older misspelled alias is also registered:

```bash
php bin/magento proudctreview:feed
```

## Feed access

- **Static feed:** `https://<store-domain>/productreview/feed/store-<store-id>.xml`
  This file is generated by the CLI command or nightly cron and can be linked
  from an external feed consumer.
- **Dynamic feed:** `https://<store-domain>/productfeed/index/feed`
  This generates XML during the request for the current store view. It does
  not read or refresh the static file.

The static feed is generally preferable for feed consumers because generation
happens before the HTTP request.

## Automatic updates

Magento cron regenerates the feed for each store view daily at 02:00, using the
Magento cron timezone. The operating-system cron must be installed and running.
You can invoke Magento's default cron group manually with:

```bash
php bin/magento cron:run --group=default
```

That command processes jobs that are due; it does not force the nightly job to
run immediately. Use `productreview:feed` for an immediate rebuild.

## Which reviews appear

- Reviews are selected for the current store view.
- Reviews of every Magento status are considered, including approved, pending,
  and not-approved.
- The product must be enabled and assigned to that store view.
- A review must have non-empty content, a rating vote, and a product URL to be
  included. Incomplete reviews are omitted and logged.
- Ratings come from Magento rating votes; the module does not invent a rating.
- Reviewer names are exported anonymously.

## Public-feed privacy warning

Both feed URLs are public and do not require authentication. Because all review
statuses are currently included, pending and not-approved review content may
be exposed. Confirm this behavior is acceptable before sharing the URL or
submitting it to a third party.

## Troubleshooting

### The command is not recognized

Confirm the module is enabled, then refresh Magento configuration:

```bash
php bin/magento module:status Pkgroup_Productfeed
php bin/magento setup:upgrade
php bin/magento cache:flush
```

### The static XML file is missing

Run the CLI generation command and check that the Magento process can write to
`pub/productreview/feed/`.

### The feed has fewer reviews than the Magento Admin list

Reviews missing text or rating votes cannot be included in the Google review
feed. Also confirm each product is enabled, assigned to the requested store
view, and has a product URL.

### The nightly file is stale

Check that Magento system cron is running, the default cron group is processed,
and inspect Magento logs for generation errors.
